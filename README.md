# 💰 EMI Calculator

A clean and responsive EMI Calculator web application built with
HTML, CSS and JavaScript.

This project was created as a side-quest web project and is designed
to calculate monthly EMI, total interest payable and total repayment
amount for different types of loans.

## 🌐 Live Website

https://emicalculatorwebpage.framer.website/

## ✨ Features

- 🚗 Car Loan calculator
- 🏍️ Bike Loan calculator
- 📱 Mobile Loan calculator
- 🏠 Home Loan calculator
- 🪙 Gold Loan calculator
- 💼 Personal Loan calculator
- 💰 Indian Rupee (₹) formatting
- 📊 Monthly EMI calculation
- 💸 Total interest calculation
- 🧾 Total repayment calculation
- 📅 Loan duration calculation
- 🎚️ Interactive sliders
- ⌨️ Manual number inputs
- 📱 Fully responsive design
- 📩 Email calculation result
- 💬 SMS calculation result
- 📄 Download calculation information
- 📋 Generate payment schedule

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Browser APIs

No frameworks or external libraries are required.
